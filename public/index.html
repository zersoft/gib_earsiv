Excel ile Toplu Fatura Yükleme & Aktarım

Excel listenizi yükleyin, otomatik doğrulansın ve tek tıkla resmi GİB taslaklarına dönüştürülsün.

Örnek Excel Şablonunu İndir (.xlsx)

Doldurduğunuz Excel Dosyasını Sürükleyip Bırakın

veya dosya seçmek için tıklayın (.xlsx veya .xls formatı)

Excel Formatı ve Kurallar:

  • TCKN_VKN: Kurumsal müşteriler için 10 haneli VKN, şahıslar için 11 haneli TCKN girilmelidir.
  • ALICI_UNVAN_AD_SOYAD: Şirket ünvanı veya şahıs ad soyadı zorunludur.
  • BIRIM_FIYAT & MIKTAR: KDV hariç birim fiyat ve adet giriniz. Matrah, KDV ve Genel Toplam sistem tarafından otomatik hesaplanacaktır.
  • KDV_ORANI: 0, 1, 10 veya 20 olarak girilebilir (varsayılan 20).

GİB e-Arşiv Fatura Microservice API

RESTful JSON API

Bu servis bağımsız bir ürün ve mikroservis olarak çalışır. SaaS platformunuzdan, e-ticaret sisteminizden veya ERP yazılımınızdan doğrudan HTTP JSON çağrıları ile fatura kesebilirsiniz.

1. MERNİS & Vergi Dairesi Sorgulama

POST /api/query-mernis
Content-Type: application/json

{
  "vknTckn": "11111111111"
}

2. Resmi Taslak Fatura Oluşturma

POST /api/invoices/draft
Content-Type: application/json

{
  "vknTckn": "11111111111",
  "aliciAdi": "Ahmet",
  "aliciSoyadi": "Yılmaz",
  "aliciVergiDairesi": "Nilüfer V.D.",
  "items": [
    {
      "malHizmet": "Yazılım Danışmanlık Hizmeti",
      "miktar": 1,
      "birim": "ADET",
      "birimFiyat": 1500,
      "kdvOrani": 20
    }
  ],
  "not": "Online Tahsilat"
}

3. SMS OTP Gönderme ve Resmi İmzalama (Mühürleme)

// 1. SMS Kodunu Tetikle
POST /api/sms/send

// 2. Kullanıcıya gelen SMS Kodunu Gir ve İmzala
POST /api/sms/verify
{
  "smsCode": "123456",
  "oid": "...",
  "ettn": "uuid-fatura-ettn",
  "belgeNumarasi": "GIB2026000000001"
}

4. Resmi İmzalı Arşiv Dosyası İndirme (ZIP)

GET /api/invoices/{ettn}/download?onayDurumu=Onaylandı
